## Movie Recommendation System using NLP and Python

### Abstract
The Movie Recommendation System recommends movies that are similar to a movie selected by the user. The system uses Natural Language Processing to process movie information such as title, genre and overview. TF-IDF converts the text into numerical vectors and cosine similarity compares the vectors. The highest-scoring movies are displayed through an attractive web interface.

### Objectives
1. Build a simple AI-based movie recommendation system.
2. Apply NLP to movie text.
3. Convert text into numerical features using TF-IDF.
4. Calculate similarity using cosine similarity.
5. Provide recommendations through an interactive interface.
